## How it works

`main.py` (Python 3.13, standard library only, no network) copies the finished `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). The image itself was drawn programmatically (Pillow) as a clean infographic — big type, five labelled story panels — so every word and number stays exact. Two runs write identical bytes.
